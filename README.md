# FitLog

FitLog is a workout planning and tracking web application where users can explore workouts, view workout details, create their personal workout plan, and track completed exercises.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Toastify
- REST API
- LocalStorage

## Key Features

1. **Workout Library**
    - Browse workouts from the workout API.
    - Workouts are displayed in a responsive card-based layout.

2. **Workout Details**
    - View detailed information about each workout.
    - See workout image, description, equipment, duration, calories, and rating.

3. **Add Workout to My Plan**
    - Users can add workouts to their personal workout plan.
    - Selected workouts can be stored using LocalStorage.

4. **My Plan**
    - View all planned workouts in one place.
    - Users can manage their planned workouts.

5. **Workout Progress Tracking**
    - Mark a workout as completed.
    - Remove unwanted workouts from the plan.
    - Toast notifications provide feedback for user actions.
